# hex-dump-core

Hexdump clássico: bytes para linhas offset/hex/ascii e releitura
estrita de volta. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 5 testes com ida-e-volta 0–255, sem dependências
npm run demo
```

No máximo 1 MiB. MIT — veja `LICENSE`.
